# 知衡资料采集与知识构建

## 使用入口

双击 `D:\zhishiku\新版知衡知识库.lnk`。资料与检索中可输入“什么是飞机机身”“机翼”“机身框静强度仿真”。定义先展示完整术语卡，正文命中展示页段和原件链接。

原始资料存放于程序的 `data/assets/<分类>/<SHA256>.<格式>`。原始目录只读，按字节哈希去重，不把同名文件当作同一内容。`D:\zhishiku\资料分类目录\打开分类目录.html` 可直接浏览分类原件。

## 可复用模板

保留16类模板：材料、术语、网格策略、工况、资料、模型、案例、流程、Skill、Tool、验证基准、失败经验、任务、运行、缺口、训练/评测登记。

- 卡片作为完整对象保存。原CSV整行保留在 `original_record`，不切碎参数、适用条件和限制。
- 材料每个参数分别保存名称、数值、单位、来源；未知数值为 null。不得把厚度、PSHELL、PCOMP当材料本体参数。
- 原文单独按页切片，保留文件ID、页码及原文；不把切片当整张卡片。
- 文献案例指向实际报告；方法准备案例记录步骤与缺口。未提供输入、日志、结果或显示证据的，明确为待补，不能称为已求解案例。
- 模型原件与几何/网格/结果语义独立登记；文件名相近不能自动证明同一求解链。STEP/IGES/BREP、支持的BDF壳与线、STL/OBJ可预览。CATPart、INP、OP2及含外部INCLUDE依赖的输入等，需要对应解析器或完整工程依赖；原件可检索和打开。

## 智能体调用

每次读取 `desktop-framework/release/知衡仿真知识库/data/runtime.json` 获取本次 `url`，不要硬编码历史端口。服务仅在本机监听；当前未更改或连接外部智能体配置。

| 接口 | 返回内容 |
|---|---|
| GET /api/search?q=机身框静强度仿真&type=case | 对象、适用性、命中页段；limit/offset分页，category分类过滤 |
| GET /api/answer?q=什么是飞机机身 | 可引用定义/摘要摘录，明确非大模型生成 |
| GET /api/objects/{id} | 完整卡片及版本、内容哈希 |
| GET /api/objects/{id}/files | 受管原件与来源附件 |
| GET /api/objects/{id}/evidence?page=2 | 原始正文及页码；可用offset分页 |
| GET /api/graph?focus={id}&hops=1 | 有依据的邻接关系；界面最多200节点 |
| POST /api/packages | 用object_ids冻结任务知识包，executable始终为false |
| GET /api/datasets/candidates?kind=cards | 卡片JSONL；也支持cases/tasks |
| GET /api/collection | 原件、分类、正文及扫描缺口统计 |

训练导出明确包含 `training_ready=false`。来源许可、人员复核、家族分组与训练/评测隔离未通过前，不宣称可直接训练。`collection/exports`另有便于离线使用的完整对象JSONL。未执行模型微调。

## 继续采集

运行 `D:\zhishiku\继续采集与入库.ps1`。Scrapy 负责公开来源采集，来源种子与允许域名在 collection/crawl.py、crawl_basics.py 中；实际URL、状态、文件哈希在 public-manifest.jsonl。只追加原件，重复内容复用。失败写入日志，不能以请求发出代替采集成功。

GitHub工具：[Scrapy](https://github.com/scrapy/scrapy)。独立依赖环境在 collection/.venv，精确版本在 requirements-lock.txt。没有安装到旧知识库环境，没有自动运行下载的脚本或求解器。

## 质量边界

`text_indexed`：可提取文字已索引；`needs_ocr` / `partial_needs_ocr`：全部/部分页疑似扫描或低文字量图页，待OCR核对；`format_pending`：原件已登记，尚无正文解析；`large_text_pending`：大文本暂不解析；`parse_error`：解析失败；`model_registered`：模型原件登记。

可按名称查到原件不代表扫描页内容已能检索。词法与术语别名检索不是大模型语义问答，不保证任意提问都正确。当前没有embedding或LLM调用；找不到依据就返回未命中，不编造参数和结论。

来源标题和目录只用于候选分类，不证明技术内容、适用性或规范现行性。历史卡片即使写“可直接执行”，导入后仍是候选。正式MOC、工程复核、适航批准与发布均不由本次采集代替。
