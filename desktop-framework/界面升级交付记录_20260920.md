## 修改内容

1. 切片默认卡片列表：正文/文件名/对象标题/标签检索，分类、文件和质量/编码筛选；内部 ID 移至高级区域；原文片段与新编码单元分别计数。摘要高亮、完整正文、来源、独立状态、原件与对象入口。
2. 宽幅切片详情：保留换行；实际编码文本、tokens、重叠、父片偏移、规则、模型版本及哈希折叠展示；分页、筛选和返回位置保存。
3. 邻片：同文件、登记 PDF 页码优先；对可用 PDF 核验原文件 SHA-256，再在原页提取文本中做唯一精确匹配，以字符偏移恢复同页片序。不用数据库 ID 冒充原文顺序；源文件缺失、文本不匹配或重复歧义时明确禁用不可靠邻片。
4. 图谱：默认实际对象网络，保留分类总览/局部一跳两跳；按真实邻接组取批次，新增节点、渐进显示和范围统计；深色画布、固定类型颜色、邻居高亮、碰撞抑制标签、可换行图例、右侧滚动详情。
5. 图谱正确性：画布/详情/关系共用后端与快照；历史字段只取版本和哈希一致的历史记录；后端切换立即清除旧详情；详情分页独立于画布限量；有请求代数保护；锁定时不执行同步模拟 tick，已有节点坐标固定；适配仅首次进入或明确操作，视角锁定允许用户手动缩放。
6. 差异：新增/缺失/变化计数与可点击清单，逐项比较主库和派生内容。
7. 内容质量：空白、独立数字页码嫌疑、版权文本、网页导航、明显解析替换字符；按文件试点还检查重复页首/页尾行。疑似项保持可查；公式、单位和参数不因长度排除。人工确认/恢复/撤销有原因、文本哈希和事件记录。原始正文不改动。关键词命中、向量命中在进入融合前使用相同质量资格；质量修改令旧检索快照失效，不更改编码版本或清空索引。
8. Wiki 入口：现有出链、反向引用、候选接受/拒绝/撤销复用；对象详情新增建立关系入口和已有/待处理/暂无关系提示。仍保留现有规则对缺失引用的诊断提示；共现与语义建议没有被新增为已确认关系。
9. 模型列表卡片化：原件、格式、版本、审核、单位、坐标系、缺口与图谱/预览入口；没有可靠层级字段的对象显示“层级待确认”。复用既有 CAD/壳线网格/表面预览模式与计数，不增加求解能力。
10. 检索跳转：关键词片段、v2 编码 key/子片、关系路径及模型预览入口；图谱节点可限定自身及直接关联对象的资料检索。Semantica 仍是单一图谱后端。
