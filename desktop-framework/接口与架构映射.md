# 知衡框架接口与 PDF 映射

知识库独立运行。没有连接DSH/PI，没有修改Agent文件或MCP配置。只读参考 D:\CAE-AGENT-DSH\tools\cae_viewer_mcp\mcp_server.py 的 loopback 工具接口模式；知识库不转发 /api/v1/cae 执行命令。

启动时选择独立空闲端口。实际地址写入程序 data/runtime.json；可验证 /api/health 的产品名及 data_root，再使用。仅绑定127.0.0.1，拒绝跨来源浏览器写入。当前面向同一用户本机使用，尚无多用户身份鉴权。

| PDF要求 | 当前实现 | 边界 |
|---|---|---|
| 第1–3页：统一底座、完整卡片 | SQLite权威对象，16种模板，完整字段读写 | 不导入语料，不切片 |
| 第3–4页：来源、版本和状态 | 字段来源、版本快照、哈希、候选/冲突/停用 | 不以置信度自动升级 |
| 第4–5页：对象/关系/区域映射 | 有依据的边、版本失效提示、区域映射模板 | 映射未自动测量和绑定 |
| 第5–6页：条件检索与任务包 | 字面/别名检索、分析类型筛选、版本化快照与缺口 | embedding未配置；完整适用性审核未实现 |
| 第7页：流程/Skill/Tool契约 | 目标、前置条件、I/O、工具版本、检查、停止条件模板 | 只登记，不执行 |
| 第8–9页：执行证据和经验回流 | 运行/案例/失败/验证/训练评测登记 | 无求解器编排，无自动复核或训练 |
| 第9–10页：Semantica | 0.6.8 GraphBuilder实际派生；单独EXE组件 | 未采用其LLM、自动抽取、SHACL与推理能力 |
| 第10–11页：独立桌面产品 | EXE自动启动知识内核，独立data，备份/恢复 | 便携目录版；无系统安装器 |

## REST契约

| 操作 | 接口 | 返回或约束 |
|---|---|---|
| 产品状态 | GET /api/health | 数据位置、数量、索引修订、Agent未连接 |
| 模板目录 | GET /api/templates | 16类字段定义和合法关系 |
| 空白模板 | GET /api/templates/{type} | 所有业务值为空 |
| 检索 | GET /api/search?q=&type=&analysis_type=&status=&limit= | 完整对象、命中理由、适用条件待确认；最多500条 |
| 读取完整对象 | GET /api/objects/{id}?version= | 当前或历史完整记录 |
| 新建/回流 | POST /api/objects | type/title/data；默认candidate |
| 编辑 | PUT /api/objects/{id} | 必须传当前version；过期返回409 |
| 历史 | GET /api/objects/{id}/versions | 不可变快照 |
| 关系 | POST /api/relations | source/target/type/evidence，锁定端点版本 |
| 有限邻域 | GET /api/graph?focus=&hops=1&type= | 最多200节点；1/2跳；stale标记 |
| 图谱派生 | POST /api/semantica/rebuild | 真实组件状态与主库revision |
| 任务知识包 | POST /api/packages | title/object_ids；完整快照、缺口、executable=false |
| 任务历史 | GET /api/packages | 冻结任务包 |
| 模板导入 | POST /api/import | 单个模板记录，强制候选 |
| 知识导出 | GET /api/export | 对象、关系、模板；恢复使用ZIP备份 |
| 附加原件 | POST /api/objects/{id}/files | multipart file；复制、哈希、150MB限制 |
| 附件目录 | GET /api/objects/{id}/files | 文件ID、哈希、受管路径 |
| 原件 | GET /api/model-assets/{file_id}/file | 只返回登记且校验通过的文件 |
| 网格显示 | GET /api/model-assets/{file_id}/mesh | BDF壳/线及STL/OBJ表面 |
| 完整备份 | GET /api/backup | SQLite一致性快照+受管文件ZIP |
| 恢复校验 | POST /api/restore | multipart file；新目录恢复、不覆盖当前空间 |

Agent未来应先读取实际OpenAPI（/openapi.json），再提交任务信息。运行回流用 type=run，缺口用type=gap，案例候选用type=case。回流记录不接受自行声明reviewed状态。没有读取或复制Agent密钥；尚未进行真实Agent端到端接入验收。

Semantica上游：https://github.com/semantica-agi/semantica 。独立开源项目，非Palantir官方产品。采用对象—关系—动作契约思想，不宣称实现Palantir全部能力。
