# 知衡工作台 1.6 · 可信问答与原文阅读

## 日常使用

仍从 `D:\zhishiku\新版知衡知识库.lnk` 启动。

- 工作台：输入问题可先“只检索”。点击“模型设置”，填写兼容 Chat Completions 的 API URL、模型、Key，选择思考模式，保存并测试后使用“检索并回答”。
- API URL 通常填写到 `/v1`；也接受完整 `/chat/completions` 地址。思考默认不传额外参数；其他模式须按服务商选择参数格式。
- Key 用当前 Windows 账户的 DPAPI 加密保存，不在 API 响应和页面回显。留空保持原 Key，勾选清除才删除。更换 Windows 账户后需重新填写。
- 远端问答默认关闭。先在模型设置明确启用，再在命中文件的原文侧栏“资料使用范围”授权该版本；只要有一份命中资料未授权，整次远端请求就不发送。文件版本变化后需重新确认。更换 URL 会取消全局授权；Key 不等于资料外发许可。
- 问答只发送问题及必要引文，不发送整库、本地路径或无关对象元数据。每条结论绑定真实引文、页码及文件版本；程序核验来源，模型另做一次支持性核对。核对失败则隐藏结论，这不是工程审批，也不能保证模型判断绝对正确。
- Embedding 复用现有本地 BGE-M3，无需另填 Key；问答模型与向量模型相互独立。新索引“就绪”不等于已经切换为当前检索索引，本次升级不改动现有索引选择。
- 原始资料：只列 document 类型关联的原文件，按原有分类浏览，可查文件名、标题、标签与已解析全文。点击文件名打开右侧原文；“打开”保留原件入口。卡片和模型分别留在各自模块。
- 原文侧栏保存当前文件版本、页码、同页片段组和阅读滚动位置；返回资料模块保留搜索与分类。PDF 支持展开原件。旧资料同页片段缺少可靠顺序时会明确提示，不以数据库 ID 冒充原文顺序。未解析的文件需打开原件阅读。
- 知识卡片、流程与能力、运行与验证：四类并排，点击分类看已登记内容。模板协议保留给 Agent，日常界面不要求手工导入模板。
- 原文片段/索引和任务知识包折叠在“高级查看”。独立知识加工页及导入质量导航不再显示。

## 后台 Agent 接口

从正式程序 `data/runtime.json` 读取当前 loopback URL；不要固定端口，也不要开启公网访问。

桌面窗口通过一次性启动凭据建立本机所有者会话；普通匿名 API 读取和写入均被拒绝。Agent 需在模型设置的折叠区生成凭据，发送 `Authorization: Bearer <token>`。只读凭据允许检索，资料处理凭据另允许下列显式提交接口；两者都不能修改模型/外发规则或人工审批。凭据可撤销，应用关闭后失效。本版没有多人账户或项目级 ACL，也不隔离同一 Windows 账户下的恶意程序。

- `POST /api/assistant/ingest`：multipart 字段 `file`，提交用户明确授权处理的文件。先保留原件、去重、解析，再进入后台处理。
- `POST /api/assistant/files/{file_id}/process`：把已登记文件加入同样的处理流程。
- `GET /api/assistant/jobs`：检查处理进展。后台依次调度抽取、来源校验、候选登记及索引维护；不全盘扫描。
- `waiting_model` 表示原件已保存，但知识抽取模型尚未配置，不是处理完成。沿用原知识运行时配置 `ZH_PIPELINE_MODEL` 及其本机模型服务；工作台的远端问答 Key 不会偷偷用于上传抽取全文。
- 有冲突、出处歧义、模型错误等进入 `needs_attention`，由管理 Agent 排查。自动校验只登记候选，不能产生人工工程审核、许可或批准。
- 后台旧 API、模板和数据库记录保留，页面精简不删除能力或历史数据。

## 增量与恢复

- 对象、文件、正文、关系和来源变更进入与主库事务一致的事件队列；失败事务不会留下虚假事件，重复消费不会重复排队。
- 回答保存版本绑定的证据快照及依赖；读取历史运行时重新核验来源，失效显示 `source_state=stale`，不静默改写历史结论。
- 向量更新在候选副本中进行，保留当前索引和原有新索引；重启后可复用已完成单元。未变化正文复用分片及向量，元数据变化不强制重算正文向量。
- 图谱与候选向量通过版本检查后才发布向量指针并记录发布清单。主库刷新中变化则再次排队；异常保留断点，由 Agent 排查重试，不无限消耗预算。
- 当前仍扫描源记录并可能重建图谱，尚非所有阶段都按变更项局部更新；各组件通过版本/出处校验拒绝陈旧结果，并非跨 SQLite 和文件系统的分布式原子事务。

## CAE 能力来源

`src/static/cae-catalog.json` 保存 `D:\CAE-AGENT-DSH` 中两项 CAE Skill、其参考文件和 `cae_viewer` 的 68 项 Tool 契约快照，包括源码路径、行号及 SHA-256。由 `scripts/catalog_cae.py` 从真实文件及 Python AST 提取，没有执行 CAE 源码。执行环境仍由 CAE Agent 管理；这不是知识库内新增的求解器连接。

## 设计与验收边界

布局参考 [shadcn/ui](https://github.com/shadcn-ui/ui) 与 [Outline](https://github.com/outline/outline) 的紧凑导航、文档列表和低干扰层级，自行实现，未替换原技术栈。

自动测试使用隔离数据及明确标注的模型响应夹具。实际模型服务须在填写真实 URL / Key / model 后通过“保存并测试连接”验证；不能把夹具通过当作真实模型连通成功。
