- Python 3.12.14（Codex bundled runtime）
- pypdf 6.1.1
- pyNastran 1.4.1（BDF/OP2；NumPy `<2` 环境）
- Semantica 0.6.8（独立 NumPy `>=2.0.2` 环境，仅 GraphBuilder 探针）
