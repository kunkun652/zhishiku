# 5 分钟演示（历史记录）

> 本文记录 2026-09-18 的旧演示验收步骤。相关根目录启动脚本已经移除，不能作为当前正式知识库的操作说明；当前入口见 `../新版知识库入口说明.md`。

1. 运行 `D:\zhishiku\启动知识库.ps1`，打开 <http://127.0.0.1:8765>。首页核对 130 个活动对象、11 个资产和 DeepSeek“未配置”。
2. 在“资料与依据”搜索 `DPW-W1`，确认带连字符查询正常；再搜索 `Pazy`，打开页 1，核对正文和“打开登记原件第 1 页”。
3. 在“四类知识卡”打开任意材料卡，确认整条字段、CSV 行号和原件入口；加入任务包不会自动建立工程绑定。
4. 在“模型与案例”依次切换：DPW-W1 为 4 网格块/85 顶点/72 三角形；frame STEP 为 1 网格块/85,420 顶点/81,088 三角形，可旋转缩放并显示实际加载耗时；plate 为 36 节点/25 单元并关联 OP2；wingbox 为 2,675 节点/2,657 单元/4,928 表面三角形；framedeck 为 318,738 节点/889,052 CTETRA/635,318 外表面三角形。frame 与 framedeck 关系待确认，后两个 BDF 无登记结果。
5. 在“任务知识包”选 CAD 案例、材料卡和工况卡，确认仍为 `executable=false`，并列出未审核绑定/单位/求解链缺口。选 plate 案例时确认资产含 BDF 与 OP2。
6. 在“导入与质量”查看资产版本、SHA-256 和登记副本；核对 wingbox 重复路径只登记一次。
7. 打开“DSH 智能助手”，确认原生 DSH 会话列表、工作区选择、消息输入和“CAE模式”直接显示在工作台内。核对技术证据中的同一 3088 DSH 已挂载知识 8 工具和 Viewer 68 工具，Viewer 连接端口来自本次项目 CAE PID 动态发现。裸 `127.0.0.1:3088` 返回 401、普通直访 `/dsh/embed` 返回 403 是鉴权生效；模型真实调用要在隔离 DSH 配置后另行验收。
8. 调用知识 MCP 的 `kb_preview_asset(mesh-wingbox)`，打开返回 URL，确认直接激活 wingbox 标签并显示 2,675 节点、2,657 单元、4,928 表面三角形；文档类资产应返回 `preview_supported=false` 和只读 `file_url`。
