# 知衡仿真知识库

当前正式产品位于 `desktop-framework`，是本地运行的航空 CAE 知识库桌面程序。它提供原件与正文检索、结构化知识卡片、模型预览、二维/三维知识图谱、任务知识包以及候选知识与人工复核边界。

## 使用

本机构建产物不提交到 Git。已构建环境可运行：

```text
D:\zhishiku\desktop-framework\release\知衡仿真知识库\知衡仿真知识库.exe
```

也可使用本机的“新版知衡知识库”快捷方式。源码构建和数据位置见 [desktop-framework/README.md](desktop-framework/README.md)，资料采集与入库说明见 [collection/接口与数据说明.md](collection/接口与数据说明.md)。

## 仓库结构

- `desktop-framework/`：正式桌面程序源码、构建脚本和测试。
- `collection/`：公开资料采集、提取、卡片构建与入库流程。
- `docs/`：接口、来源和历史验收说明。
- `scripts/`：采集、导入及诊断辅助脚本；部分文件属于历史演示。
- `integrations/dsh/`、`app/`、`server/`：保留的历史演示源码，不是当前正式 EXE 的启动入口。

## 数据与边界

正式数据在构建产物的 `data` 目录中，不进入 Git。知识候选、自动检查、人工工程复核、正式发布和批准保持独立；图谱关系和相似检索不代表工程适用性已经确认。

根目录旧演示启动脚本、设计 PDF、交互原型及已完成的实施计划已在后续整理中移除。历史提交仍可用于恢复和追溯。
